**Family:** [Govern](/patterns). Decide how the deciding goes. **Example:** Never use this color, or a spending cap.

## When to use it

Use it to decide once, for every future case.

## What a good design needs

A good design shows what the rule would have caught in the past.

## How it fails

It fails when a rule is hidden, or when you cannot see what it does.
